# Interaction specification

## Entry

The pre-entry loader must not show the 1maginator name. It begins as an unexplained neutral signal field.

After roughly 2.5-3.5s of idle time, nearby glyphs self-organize into a thin living guidance thread. The thread travels as a wave, bends naturally, reforms into an arrow, and briefly reveals tiny PRESS text pointing at the entry control.

## Guidance thread

It must be formed from the same visual material as the scene, not a separate tooltip. Pointer proximity can deform it slightly. On touch, it should remain readable without hover.

If the user interacts before the hint appears, cancel it. If ignored, a second hint may happen only after a much longer delay and should vary subtly.

## Press

The user gesture unlocks audio. The entry object responds physically, the neutral palette emits a brief cold-blue energy event, glyphs/particles disperse, and the 1maginator identity is revealed for the first time.

## Navigation

Navigation labels stay simple: about, work, code, sound, links. Route changes feel like state transitions of one continuous world rather than five unrelated pages.

## Motion character

Prefer inertia, waves, reconstruction, attraction/repulsion, and material continuity over generic fades/scales. Motion should remain interruptible and responsive.

## Reduced motion

Replace long travel, particle swarms, and intense glitch with short opacity/state changes while preserving content and navigation.
