# Creative brief

## Product

imaginator.one is a personal audiovisual site for 1maginator: code, music, visual experiments, selected work, and links.

## Desired feeling

Quietly strange, tactile, alive, human, memorable. The site should feel like a digital object discovered on the web rather than a résumé template.

## Visual DNA

- Black / near-black space with off-white signal material.
- Cold electric blue appears as a reward or energy event, not the default palette.
- Authentic dithering, ASCII/glyph density, point clouds, scan texture, subtle phosphor bloom.
- Sketch/DIY internet-underground energy from the existing SoundCloud identity.
- Rare datamosh/glitch transitions used with restraint.

## Content

- Home: immersive entry, short human intro, selected work.
- About: compact personal text, not corporate biography.
- Code: two GitHub identities - imaginatorone (primary) and sensorywave (secondary).
- Sound: custom presentation with lazy SoundCloud playback.
- Links: Telegram imaginatorone, YouTube @1maginatorone, both GitHubs, SoundCloud.

## Anti-goals

No fake terminal roleplay, "access granted", Matrix rain, generic portfolio copy, giant rounded cards, stock illustrations, gratuitous 3D, or noise that harms reading.
