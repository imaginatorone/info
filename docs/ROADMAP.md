# Roadmap

## M0 - foundation

Status: complete.
Project architecture, design/data/audio/performance notes, build tooling, tests, and a clean React shell are in place.

## M1 - entry scene

Implement the pre-brand signal field, hidden identity, entry control, idle ASCII guidance thread -> arrow -> PRESS, explicit audio unlock, and first reveal. Desktop and touch must both work.

## M2 - persistent world + routing

Keep one visual world alive while routes change between home, about, code, sound, and links. Implement state transitions rather than independent page backgrounds.

## M3 - code

Integrate public data for imaginatorone and sensorywave, curated featured repos, graceful caching/errors, and visual GRID signatures.

## M4 - sound

Build custom track presentation, lazy SoundCloud integration, procedural soundscape buses, and WAVE visualization.

## M5 - polish

Adaptive quality governor, reduced-motion path, accessibility, Playwright visual QA, loading strategy, metadata, deployment, analytics/privacy decision, and final copy.

## Rule

Finish one milestone to its acceptance criteria before expanding visual scope.
